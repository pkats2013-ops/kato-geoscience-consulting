Kato Geoscience Consulting
==========================

A ready-to-use classic WordPress theme for a geological and geophysical consulting website.

INSTALLATION
1. In WordPress, go to Appearance > Themes > Add New Theme > Upload Theme.
2. Upload kato-geoscience-consulting.zip, install it and activate it.
3. Set your site title under Settings > General. Optionally add a logo under Appearance > Customize > Site Identity.
4. Edit the ready-made homepage text and contacts under Appearance > Customize > Consulting Homepage.
5. Optionally create a navigation menu under Appearance > Menus and assign it to Primary Menu.

The homepage displays automatically on the front page. It includes starter sections for an introduction, services, approach and contact details. Existing WordPress pages, posts, site title, logo and menu can be edited through the dashboard.
